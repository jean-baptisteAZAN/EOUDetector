Towards Semantically-Aware End-of-Utterance Detection for Conversational AI Systems

Jean-Baptiste Azan Supervisor: Palani MSc project corpus, August 2026

Real-time detection of when a caller has finished speaking, for a French medical voice agent, by fusing an acoustic signal (Smart Turn v3) and a lexical signal (CamemBERT) over a voice-activity gate, with a calibrated, cost-sensitive endpoint decision. Fusing audio and text raises the per-span accuracy score from 0.814 to 0.897 (improvement 0.083, 95% confidence interval [0.063, 0.104], p < 0.0001, clustered bootstrap by call). Evaluation uses LiveKit's public eot-bench dataset; the production data is the in-domain validation set.

Note on data

The corpus contains no patient data. The production calls (audio and transcripts) are personal medical data and are excluded for data-protection reasons; the capture pipeline is feature-flagged to internal test organisations. Included instead: the dataset-generation code and all evaluation on the public LiveKit eot-bench dataset (CC-BY-4.0). The eot-bench harness is a separate open-source repository referenced in reproduce.md.
