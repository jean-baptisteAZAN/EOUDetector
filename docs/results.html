Results: Semantically-Aware End-of-Utterance Detection

Evaluation on the public LiveKit eot-bench benchmark, French subset (400 turns). Metrics: per-span AUC (Area Under the ROC Curve), latency at a false-cutoff budget, Expected Calibration Error (ECE). All lexical and fusion numbers are k-fold by call (no leakage).

1. Setup

Everything is evaluated through the eot-bench harness, which sweeps the endpointing policy and reports the latency-versus-false-cutoff trade-off. The same code runs on the public French subset (below) and on the gold French-medical set as production data accumulates. Baselines (Smart Turn, LiveKit, Soniox, Deepgram, AssemblyAI, OpenAI) ship with the benchmark.

2. Fusion helps once the lexical model is in-distribution

Smart Turn (acoustic) is the starting point. Adding a lexical signal only helps if it fits the data: the medical-tuned CamemBERT is out-of-distribution on generic French and hurts; a lexical trained in-distribution and fused with the acoustic beats acoustic-only.

With an in-distribution lexical (frozen CamemBERT embeddings plus a logistic head, no fine-tuning), the fusion reaches AUC 0.900, above Soniox (0.888), from Smart Turn's 0.814. Caveat: we lead on ranking (AUC) but trail on latency (715 ms versus Soniox 557 ms and LiveKit 635 ms) as the commercial streaming systems commit earlier. This is generic French; the medical lexical is in-domain on the gold set, where the gap should widen in our favour.

3. Calibration is a universal gap

None of the leaderboard systems calibrate their end-of-turn probability. Measured on a held-out split, all ten are miscalibrated (ECE > 0.05), and a simple post-hoc calibration fixes every one. A calibrated probability is the prerequisite for a cost-based decision, and nobody reports it.

4. The operating point is chosen by the cost, not a fixed timeout

Given the interruption-versus-latency cost ratio λ = Ccut/Clat, the minimum-cost operating point moves predictably: the more costly an interruption, the more conservative the endpoint (lower cut-in, higher latency). The endpoint is derived, not a fixed 500 ms threshold.

λ (interruption cost)Cut-in rateLatency
1 (cheap)26.7%354 ms
57.2%699 ms
101.8%1080 ms
50 (costly)0.9%1285 ms

A calibrated cost-derived threshold tracks the swept oracle at moderate λ; at high λ the oracle turns conservative through timing (action-delay / timeout), which motivates a full sequential optimal-stopping formulation.

5. Negative results

  • Out-of-domain medical lexical on generic French lowers AUC (0.814 → 0.789): fusion only helps with an in-distribution lexical.
  • Time-aware sequential threshold did not beat the harness sweep (0.814 → 0.798): the frontier is bounded by score quality, and the sweep already extracts the temporal policy.
  • Dialogue-context augmentation of the lexical did not help (0.900 → 0.86/0.90): frozen-embedding pooling dilutes the caller's completion signal.

6. Status

Demonstrated so far:

  • End-to-end eot-bench evaluation (French, full leaderboard).
  • Fusion (frozen CamemBERT + logistic) reaches AUC 0.900, above Soniox (0.888), with no fine-tuning.
  • Calibration is a universal gap (10/10 models) and is fixable post-hoc.
  • The fused probability is itself well-calibrated (ECE 0.06) and drives the cost-based decision.
  • Cost-sensitive operating point derived from the cost ratio.
  • The fused lexical model (CamemBERT) is wired into the live pipeline (CLI and browser demo).

Next:

  • Sequential optimal-stopping decision beyond the myopic threshold.
