Results: Semantically-Aware End-of-Utterance Detection

Evaluation on the public LiveKit eot-bench benchmark, French subset (400 turns). Metrics: per-span AUC (Area Under the ROC Curve), latency at a false-cutoff budget, Expected Calibration Error (ECE). All lexical and fusion numbers are k-fold by call (no leakage).

1. Setup

Everything is evaluated through the eot-bench harness, which sweeps the endpointing policy and reports the latency-versus-false-cutoff trade-off. The same code runs on the public French subset (below) and on the gold French-medical set as production data accumulates. Baselines (Smart Turn, LiveKit, Soniox, Deepgram, AssemblyAI, OpenAI) ship with the benchmark.

2. Fusion helps once the lexical model is in-distribution

Smart Turn (acoustic) is the starting point. Adding a lexical signal only helps if it fits the data: the medical-tuned CamemBERT is out-of-distribution on generic French and hurts; a lexical trained in-distribution and fused with the acoustic beats acoustic-only.

With an in-distribution lexical (frozen CamemBERT embeddings plus a logistic head, no fine-tuning), the fusion reaches AUC 0.897, up from Smart Turn's 0.814 (a gain of 0.083). On the same per-span metric it sits above LiveKit v1-mini (0.884) but below Deepgram Flux (0.915) and LiveKit v1 (0.937). The streaming STT systems (Soniox, AssemblyAI, OpenAI) cannot be scored on this per-span AUC because of a score-point misalignment, so only their latency is shown. On latency we trail the commercial systems (715 ms versus Soniox 557 ms and LiveKit 635 ms at a 5% cut-in budget), which commit earlier. This is generic French; the medical lexical is in-domain on the gold set, where the gap should widen in our favour.

3. Calibration is a universal gap

None of the leaderboard systems calibrate their end-of-turn probability. Measured on a held-out split, all eight external systems are miscalibrated (ECE > 0.05; 13 of the 14 models evaluated overall), and a simple post-hoc calibration lowers the error for almost all of them. A calibrated probability is the prerequisite for a cost-based decision, and nobody reports it.

4. The operating point is chosen by the cost, not a fixed timeout

Given the interruption-versus-latency cost ratio λ = Ccut/Clat, the minimum-cost operating point moves predictably: the more costly an interruption, the more conservative the endpoint (lower cut-in, higher latency). The endpoint is derived, not a fixed 500 ms threshold.

λ (interruption cost)Cut-in rateLatency
1 (cheap)16.8%330 ms
55.4%674 ms
101.8%981 ms
50 (costly)0.2%1525 ms

A calibrated cost-derived threshold tracks the swept oracle at moderate λ; at high λ the oracle turns conservative through timing (action-delay / timeout), which motivates a full sequential optimal-stopping formulation.

5. Negative results

  • Out-of-domain medical lexical on generic French lowers AUC (0.814 → 0.789): fusion only helps with an in-distribution lexical.
  • Time-aware sequential threshold did not beat the harness sweep (0.814 → 0.811): the frontier is bounded by score quality, and the sweep already extracts the temporal policy.
  • Dialogue-context augmentation of the lexical did not help (0.897 → 0.854): frozen-embedding pooling dilutes the caller's completion signal.

6. Status

Demonstrated so far:

  • End-to-end eot-bench evaluation (French, full leaderboard).
  • Fusion (frozen CamemBERT + logistic) reaches AUC 0.897 (from 0.814), with no fine-tuning; above LiveKit v1-mini but below Deepgram and LiveKit v1 on the same per-span metric.
  • Calibration is a universal gap (8/8 external models, 13/14 overall) and is fixable post-hoc.
  • The fused probability is much better calibrated than the leaderboard (ECE 0.064 versus 0.2 to 0.37), lowered to 0.043 by post-hoc calibration, and drives the cost-based decision.
  • Cost-sensitive operating point derived from the cost ratio.
  • The fused lexical model (CamemBERT) is wired into the live pipeline (CLI and browser demo).

7. In-domain validation (gold): the pipeline does not transfer

The same pipeline was run on 709 production French medical calls (5,342 decision pauses, 1,015 end-of-turn / 4,327 hold, weak-supervision labels, 8 kHz telephone band). Per pause: acoustic-only (Smart Turn) AUC 0.49, lexical-only (CamemBERT) 0.60, fusion 0.59. Two causes, once bugs were ruled out (caller channel confirmed left by pre-pause speech energy; timestamp alignment and score point verified): Smart Turn is trained on 16 kHz wideband and saturates upward on 8 kHz narrowband, answering “finished” for nearly every pause; and weak supervision caps the attainable signal — label cleaning lifts the lexical AUC only from 0.60 to 0.61, for both frozen and fine-tuned models alike. The off-the-shelf pipeline does not transfer directly to production.

Next:

  • An acoustic model adapted to the 8 kHz telephone band, to remove the saturation.
  • A small hand-annotated gold subset, for a trustworthy in-domain measurement.
  • Sequential optimal-stopping decision beyond the myopic threshold.
