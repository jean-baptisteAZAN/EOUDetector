01

The unclaimed conjunction

Across five systems (2024-2026), the two pillars of our approach each appear separately, but never together, and no system reports any calibration diagnostic.

Contribution · one line

A streaming EOU detector that fuses acoustic + lexical into a calibrated completion probability, and decides via a cost-sensitive optimal-stopping rule.

Fusion systems (FastTurn, JAL-Turn) decide by argmax / a fixed threshold on uncalibrated scores. The one cost-aware system (Endpoint Anticipation) is acoustic-only and uncalibrated. The French fusion model is offline. The conjunction is open.

03

What we add, vs whom

  • vs FastTurn / JAL-Turn
    They fuse acoustic + lexical, but decide by argmax / τ=0.5 on uncalibrated scores. Calibration + an optimal-stopping decision.
  • vs Endpoint Anticipation
    The only cost-aware system, but acoustic-only, uncalibrated, per-horizon threshold. Lexical fusion + calibration + sequential optimal stopping with an explicit cost.
  • vs French terminality
    French + fusion, but offline classification of a pre-segmented chunk. Streaming real-time endpointing + calibration + cost.
  • vs the field
    Survey: 72% of works don't compare to prior; ⅓ use no public corpus; nobody calibrates. A calibrated, comparable evaluation: a contribution in itself.

06

Evaluation plan & honest caveats

  1. Sweep the cost ratio C_cut / C_lat → traces our operating curve.
  2. Plot latency-vs-cut-in for every baseline + ours; show Pareto domination.
  3. Reliability diagram + ECE, ours vs baselines (they report none).
  4. Per-category hold-rate on hard cases (spelling / number / date / hesitation).
  5. Report CPU ms/decision + params: efficiency vs LLM-based SOTA.

Say this plainly in the meeting

  • Endpoint Anticipation is close: it is genuinely cost-aware. Our edge is lexical fusion + calibration + true sequential optimal stopping, not "cost-awareness" alone.
  • FastTurn / JAL-Turn / EPA are 2026 pre-prints: numbers may shift; cite as very recent.
  • Everything downstream needs the labelled audio with t_end: latency, the operating curve, and calibration all derive from it. Data is the gating dependency.
